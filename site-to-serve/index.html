Wait, is this actually hosted on a Nintendo?

Yes! This website is being served directly from the 8-bit memory of a 1985 Nintendo Entertainment System. Because the NES wasn't designed for the internet, we've given it a "translator" - a tiny ESP32 computer that acts as a bridge between the console and the modern web.

The NES holds the website data in a highly compressed format, and when you visit this page, the NES "plays" the data through its controller port to the internet.

The Hardware Stack

The request flows through a Cloudflare Tunnel to a home server, which reverse-proxies the traffic to a USB Serial port.

Connected to that port is an ESP32-C3 Supermini. The ESP32 communicates with the NES via Controller Port 1 using a custom bit-banging protocol.

The NHF1 Compression

To fit a modern website into the NES's limited 32KB ROM banks, we developed the NES Huffman Format (NHF1). It uses two layers of compression:

  • 7-bit Dictionary Tokenization: Common HTML/CSS strings are identified and replaced with single-byte tokens (e.g., <div class= is a single byte).
  • Huffman Coding: A variable-length bit encoding based on character frequency, further shrinking the tokenized data.

When a request arrives, the NES streams the NHF1 data at "Turbo" speeds to the ESP32, which decompressses it in real-time to serve the HTML/CSS back to your browser.
